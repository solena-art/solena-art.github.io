# SOLENA Medical
The End of Regulatory Guesswork. A RAG-based intelligence engine for global medical device compliance.

## Overview
SOLENA eliminates the 'surveillance tax' for Regulatory Affairs teams by automating the tracking of changes across 52+ jurisdictions.
